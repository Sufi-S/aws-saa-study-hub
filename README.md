# AWS SAA-C03 Study Hub

A self-contained static study site for the **AWS Certified Solutions Architect - Associate (SAA-C03)** exam, built with vanilla HTML/CSS/JS and hosted on GitHub Pages.

## Exam Domains (from official AWS exam guide v1.1)

| Domain | Name | Weight |
|--------|------|--------|
| 1 | Design Secure Architectures | 30% |
| 2 | Design Resilient Architectures | 26% |
| 3 | Design High-Performing Architectures | 24% |
| 4 | Design Cost-Optimized Architectures | 20% |

## Features

- Dark-mode-first design with light mode toggle
- Per-domain progress tracking (localStorage)
- Quiz mode with scenario-based questions
- Flashcard system for key terms
- Interview prep section
- Mobile-responsive layout
- No build step required — pure static files
